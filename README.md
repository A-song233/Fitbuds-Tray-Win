# FitBuds Pro Control Tray (Windows)

轻量级的漫步者 **EDIFIER FitBuds Pro** 蓝牙耳机 Windows 桌面系统托盘控制工具，基于逆向还原的经典蓝牙 RFCOMM 私有控制协议实现，脱离手机端 *Edifier Connect* App 即可在 PC 端直接管理耳机状态。

## 核心功能

- **实时电量监控**：在托盘悬停提示与右键菜单中展示左耳、右耳及充电仓电量，自动识别单双耳佩戴状态。
- **降噪与环境声切换**：支持一键切换 `深度降噪`、`宽频降噪`、`防风噪`、`环境声` 与 `降噪关`。
- **预设音效（EQ）**：支持 `经典`、`古典`、`摇滚`、`流行` 四种内置音效切换。
- **低延迟游戏模式**：快速开启或关闭游戏模式。
- **远程关机**：支持直接向耳机发送蓝牙关机指令。
- **零依赖原生性能**：纯 C++ / Win32 API + Winsock Bluetooth 实现，常驻后台内存占用极低，支持长连接复用与秒级指令响应。

## 使用说明

1. 在 Windows 系统蓝牙设置中完成与 **EDIFIER FitBuds Pro** 的配对并保持连接。
2. 运行 `FitBudsTray.exe`，系统托盘区将出现耳机图标。
3. **右键点击托盘图标**即可查看电量并切换降噪、音效或游戏模式。

## 项目背景

本项目通过 Android HCI Snoop Log 抓包与 Wireshark 协议分析还原指令集，确认该系列耳机通过经典蓝牙 SDP 广播 `edif` 服务（RFCOMM Channel 14）进行指令收发与状态同步。理论上同协议族的漫步者 FitBuds 系列型号在匹配对应 RFCOMM 通道后亦可兼容。

## 从源码构建

将 MinGW-w64 的 `g++` 和 `windres` 加入 PATH，在 PowerShell 中运行 `./build.ps1`。也可以运行 `./fitbuds.exe battery` 在终端查询电量。
